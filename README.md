# guna-lab

Hardware and code experiments by Gunapathi Selvam, shared from my reels. Every project has its own folder
with a README: parts, wiring, setup and how to use it.

## Projects

| Project | Board | What it does |
|---|---|---|
| [digi-eyes](digi-eyes/) | Seeed XIAO ESP32C3 + 0.96" OLED | Animated face and mini smart display: clock, phone notifications and calls over Bluetooth, controlled from your phone's browser |

## Get a project

1. **Code → Download ZIP** on this page (or `git clone https://github.com/Gunapathi/guna-lab`).
2. Open the project's version folder, for example `digi-eyes/v2.1`, and open the `.ino` inside it in
   the Arduino IDE. Keep the folder name as it is: Arduino needs the folder and the `.ino` to match.
3. Follow that project's README for libraries, board settings and wiring.
